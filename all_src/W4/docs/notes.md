# W4 メモ(下書き:自分の言葉で書き直す)

## やったこと

出口(logits より後ろ)を 2 か所で差し替えた。本体(Block)は W2 のまま。

- 実験1:学習側。採点方法(損失関数)を CE / MSE に差し替えた → 重みが変わる
- 実験2:生成側。抽選方法(温度 T)を変えた → 重みは変わらない

## 分かったこと

1. T は logits の差を伸び縮みさせるつまみ。順位は変えず、確率の配分だけを変える。正確さと多様さは片方を上げるともう片方が下がる
2. 生成の質の上限は重みで決まる。T をどう選んでも、モデルの限界(存在しない単語)は消せない
3. MSE は正解率では CE とほぼ同じだが、val CE で 0.19 負けた。原因は「自信を持って外した位置」が多いこと(p<0.001 が 2.3 倍)
4. MSE の勾配には正解の確率 p が掛かるので、ひどく外した位置ほど直す力が弱くなる。CE の勾配は p − y で、ひどく外した位置ほど強く直す
5. MSE は自分のホームの val MSE でも CE に負けた。CE のほうが、限られた時間で良い確率分布にたどり着ける
6. AdamW は勾配の全体スケールを打ち消す。そのため学習率を 10 倍にしても、バッチ内の配分(外した位置の声が小さい)は変わらず、MSE の差は縮まらなかった

## 仮説の検証

- 仮説:初期値やスケールを調整すれば MSE も活躍できる
- 結果:学習率 10 倍では支持されなかった
- ただし AdamW のもとでは「スケールを補う」実験になっていない
