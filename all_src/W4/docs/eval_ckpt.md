# W4 実験1:採点方法(損失関数)の比較

## 条件

- モデル:W2 の GPTMini(V=65, d_model=64, block_size=32, n_layer=4, 4 head)
- データ:tiny_shakespeare(train 1,003,854 文字 / val 111,540 文字)
- 学習:AdamW, lr=1e-3, batch_size=32, 3000 iter, seed=0
- 変えたもの:損失関数のみ

| tag | 損失関数 | 学習率 |
|---|---|---|
| ce | CE | 1e-3 |
| mse | MSE(softmax 後の確率と one-hot。65文字で合計、位置で平均) | 1e-3 |
| mse_lr*10 | MSE | 1e-2 |

## 学習中のログ(300 iter ごと、val からランダムに 50 バッチ)

| | iter 0 の lm_head 勾配 | 最終 val CE | 最終正解率 |
|---|---|---|---|
| ce | 6.90e-01 | 1.8223 | 46.2% |
| mse | 2.37e-02 | 2.0133 | 45.1% |
| mse-lr*10 | 2.37e-02 | 2.0151 |　45.1% |

- iter 0 の val CE は ce・mse ともに 4.3217(同じ seed・同じ初期値)
- mse の iter 0 の勾配は ce の約 1/29(予想は 2/65 ≈ 1/32)
- val CE の差は iter 1500 までに 0.19 まで開き、その後は平行に推移した
- 図:compare.png

## 学習後の採点(eval_ckpt.py、val 全体を block_size ごとに区切って評価。揺れなし)

| | val CE | val MSE | 正解率 | p 中央値 | p<0.01 | p<0.001 |
|---|---|---|---|---|---|---|
| ce | 1.8157 | 0.6687 | 46.29% | 0.2165 | 5.26% | 0.77% |
| mse | 2.0080 | 0.6815 | 45.37% | 0.1794 | 8.06% | 1.76% |
| mse_lr*10 | 2.0120 | 0.6832 | 45.32% | 0.1791 | 8.26% | 1.45% |

p は正解の文字に置いた確率。

## 読み取れること

- ce は mse ,val MSE の二つに対して損失関数が最も低い。差は物差し(mse,ce)の有利不利だけでは説明できない
- 正解率の差は 約0.9 ポイントだが、val CE の差は 0.19。差は「1位を当てる力」ではなく「外したときの確率の置き方」にある
- p<0.001 は mse が ce の 2.3 倍、p<0.01 は 1.5 倍。極端な外れほど倍率が大きい
- p<0.001 の位置の差(約 1%)だけで、val CE の差 0.19 のうち少なくとも約 0.07 を占める(0.0099 × −log 0.001)
- 学習率を 10 倍にしても(mse_lr*10)、val CE・val MSE・正解率は mse とほぼ同じ。p<0.001 は 1.45% で、ce の約 1.9 倍のまま

## 注意点

- 初期値における乱数（seed）は固定 
- AdamW は勾配の全体スケールを打ち消すため、mse_lr*10 は「スケールを補う」実験ではなく「歩幅を大きくする」実験になっている
