## 基準

- 設定:block_size 32、batch_size 32、d_model 64、n_layer 4、lr 1e-3、weight_decay 0、seed 0
- 全データ・3000 iter(約3.1エポック)、eval_interval 150
- 結果:最終 val CE 1.8307 / train CE 1.6626 / gap 0.168 / val acc 0.461
- 過学習はしない(val は下がり続ける)

## これまでに分かったこと

- 「gap が開く」ことと「val が上がる」ことは別。過学習と判断するのは後者
- val が1点だけ上がることはある(iter 2850:1.8289 → 3000:1.8307)。1点の上昇だけでは過学習と判断しない
- eval_interval を変えても学習の軌跡は変わらない(150 と 300 で数値が完全一致)
- weight_decay 0.01(AdamW の既定値)の影響は、この設定ではほぼなかった(差 0.004)
- 主の物差しは CE、正解率は副。「CE は上がるが正解率は横ばい」は過学習の兆候になる
