### Week 1｜Attention を手で書く

| | |
|---|---|
| 目標 | numpy で Attention の順伝播を書く |

### Week 3｜壊して観察する【重要】

| | |
|---|---|
| 目標 | 症状と原因の対応表を作る |
| 成果物 | 実験ログ（変更→結果→仮説の表） |
| 記事 | 「学習を6通りに壊してみた」 |

1箇所ずつ変えて、何が起きるか記録する。

| 変更 | 予想される症状 |
|---|---|
| 学習率を10倍 | 発散 |
| 学習率を1/100 | 進まない |
| 層正規化を外す | 深い層で学習が止まる |
| 残差接続を外す | 勾配が届かない |
| 位置エンコーディングを外す | 語順が消える |
| 初期化を大きく | 最初から壊れる |

**この週が計画全体で一番リターンが大きい。省略しない。**

### Week 7｜出口を動作に差し替える

| | |
|---|---|
| 目標 | Physical AI の入口に立つ |
| 成果物 | 2D環境で点が目標へ動くポリシー |
| 記事 | 「同じ Transformer でロボットを動かす」 |

- 平面上の点＋障害物1つの環境を numpy で書く（数十行）
- ルールベース制御器でお手本を数百本記録
- 回帰ヘッドで学習 → ロールアウトして**破綻を観察**
- 障害物を左右両方から回るお手本を混ぜて、**平均を取って突っ込む**現象を見る

**環境を凝らない。点が動けば目的は達成。**
